# OfflineMesh 🕸️

### Private. Local. Connected.

OfflineMesh is a modern Android communication application built for **private peer-to-peer communication without traditional internet dependency**.

## ✨ Features

* 📡 Nearby device discovery
* 💬 Peer-to-peer messaging
* 🆔 Unique OfflineMesh ID
* 🔐 Cryptographic identity
* 💾 Local message storage
* 👤 Custom user profiles
* 👥 Community-based communication
* 🔒 Privacy-focused architecture
* 🎨 Modern Android interface

## 🛠️ Built With

* Kotlin
* Jetpack Compose
* Material 3
* Google Nearby Connections
* Room Database
* Kotlin Coroutines
* Android Keystore

## 🔐 Privacy

OfflineMesh is designed with privacy in mind.

* No public phone number identity
* Local-first data storage
* Cryptographic user identity
* Private keys protected by Android Keystore
* No cloud account required for local communication

**Active Development**

OfflineMesh is being developed as an independent peer-to-peer communication platform.
